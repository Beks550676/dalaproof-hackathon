# 🛡️ DalaProof (Anti-Resume)
> **Платформа технической верификации разработчиков под реальные бизнес-задачи МСБ через статический анализ кода (Python AST) и анти-чит блиц-интервью на базе Groq LLM.**

## 🔥 Проблема
1. **Кризис доверия к резюме:** В эпоху LLM любой кандидат может сгенерировать идеальное резюме и списать стандартное тестовое задание за 30 секунд.
2. **Боль локального МСБ:** Предпринимателям (ритейл, логистика, общепит, склады) нужны рабочие скрипты и автоматизация, но они не умеют писать технические задания (ТЗ) и оценивать качество кода разработчиков.

## 💡 Наше решение — DalaProof
Мы полностью убираем резюме из процесса найма и заменяем его трехступенчатым конвейером верификации:
1. **AI-Транслятор бизнес-боли (`POST /api/generate-task`):** Предприниматель описывает свою проблему обычным языком (например, *«путаются остатки скоропорта на кассе»*). Модель **Llama-3.3-70B (Groq)** мгновенно формирует из этого формализованную алгоритмическую задачу с входными и выходными тест-кейсами.
2. **Статический аудит кода (`ast_analyzer.py`):** Когда кандидат отправляет код, наш модуль на базе `ast.NodeVisitor` строит абстрактное синтаксическое дерево кода (без опасного `exec`), вычисляет цикломатическую сложность, находит ветвления, циклы и заглушки.
3. **90-секундный Анти-Чит Блиц (`POST /api/submit-code` & `/api/verify-answers`):** На основе найденных в AST-дереве конструкций ИИ генерирует 3 точечных вопроса **именно по написанному коду кандидата**. У разработчика есть 90 секунд, чтобы защитить свое решение.

## 🛠️ Технологический стек
* **Backend:** Python 3.11+, FastAPI, Uvicorn, Pydantic
* **Code Analysis:** Встроенный модуль `ast` (`ast.NodeVisitor`, подсчет сложности и извлечение узлов дерева)
* **AI Engine:** Groq Cloud API (`llama-3.3-70b-versatile`) — генерация задач и динамический блиц за < 0.8 сек
* **Database:** SQLite3 (`dalaproof.db`)
* **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript (`fetch API`)
